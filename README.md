# Koreplay

Public website, download releases, and documentation for the Koreplay Android media client. The application source code stays private; install packages for the current version are published in this repository's releases.

Koreplay is an Android media player for phones and tablets using user-configured media sources. Its optional Trakt integration lets users manage watchlists, sync episode watch history and watched progress, and view their personal episode calendar. Metadata comes from TMDB and other configured services. Koreplay does not host or provide video content.

The releases page holds one universal host APK plus the plugins for each architecture, with SHA-256 checksums. Issues are for bug reports and usage questions; keep passwords, tokens, authorization URLs, account history, and other sensitive details out of them.

Koreplay uses Trakt but is not endorsed or certified by Trakt.
